## Descripción de la Fase Descendente

### 1. Análisis de Requisitos (Requirement Gathering)
* **¿Qué se hace?** Se definen las necesidades reales del usuario y las funcionalidades fundamentales del sistema.
* **Claves:** Identificación de roles (Administrador, Gestor, Usuario, Visitante), login/registro y requisitos de seguridad.

### 2. Análisis del Sistema (System Analysis)
* **¿Qué se hace?** Se especifica el comportamiento general del software y su arquitectura funcional.
* **Claves:** Casos de uso, flujo de datos y modelo de permisos según los privilegios de cada rol.

### 3. Diseño de Software / Arquitectura (Software Design)
* **¿Qué se hace?** Se definen los componentes principales, las interfaces y la tecnología a usar.
* **Claves:** Stack seleccionado con **Python, Django, Vite.js y Docker**.

### 4. Diseño de Módulos (Module Design)
* **¿Qué se hace?** Se detalla la lógica interna, algoritmos y estructura de datos de cada módulo.
* **Claves:** Módulo de autenticación/usuarios, Django Admin y plantillas de interfaz por rol.

### 5. Punto de Inflexión: Codificación (Coding)
* **¿Qué se hace?** Es el paso de la teoría a la práctica: construcción del código fuente.
* **Claves:** Configuración de contenedores Docker, creación del proyecto en Django y control de versiones en GitHub.
